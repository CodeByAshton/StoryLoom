# Roadmap

What's planned for future builds of Motif.

## Next build

### Import and export in other file types
Bring an existing draft in, and get a finished one out, without leaving Obsidian.

- **Import**
  - Word (`.docx`), Markdown and HTML files.
  - Split the file into chapters at its headings (or at page breaks), number them, and add the chapter frontmatter.
  - Offer to run Sync on each new chapter so the codex fills in.
- **Export**
  - **Word (`.docx`)** for editors and agents.
  - **EPUB** for e-readers and stores.
  - **Print-ready PDF**: trim size, margins, chapter openers, front matter.
  - All three keep chapter order, use chapter titles as headings and strip frontmatter, like the current Markdown export.
- **Why:** most writers arrive with a draft in Word, and every one of them needs a manuscript file at the end.

## Later

- **Chat with a character**: the assistant answers in a character's voice, using what they know as of the current chapter.
